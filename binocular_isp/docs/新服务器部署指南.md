
（本地已有一把空口令密钥 `~/.ssh/id_mygpu`，直接复用；输入 zeng 的登录密码一次）

**0.2 追加 SSH 配置（新别名 mygpu2）**：

```bash
cat >> ~/.ssh/config <<'EOF'
Host mygpu2
    HostName 223.109.239.30
    Port 27024
    User zeng
```


## 第 4 步：服务器环境一键配置

```bash
ssh mygpu2 "bash /data/zeng/setup_server.sh"
```

脚本自动完成：磁盘检查 → Miniconda（清华镜像，装到 `/data/zeng/miniconda3`）→ 接受 conda ToS → 创建 rawisp（Python 3.10）→ **GPU 版 PyTorch cu124（阿里云镜像）** → ultralytics + rawpy 等依赖（清华源）→ 验证 CUDA。

**关键避坑（已内置在脚本里）**：
- 必须先装 GPU torch 再装 ultralytics（否则被覆盖成 CPU 版）；
- 新版 conda 会拦截非交互安装，脚本先 `conda tos accept`；
- 大文件全部走国内镜像，不再卡 pytorch 官网。

## 第 5 步：数据转换 + 训练（tmux 托管，断网免疫）

```bash
# 5.1 转换 COCO → YOLO（约 1 分钟）
ssh mygpu2 "tmux new -s conv -d 'cd /data/zeng && /data/zeng/miniconda3/envs/rawisp/bin/python binocular_isp/scripts/coco_to_yolo.py --ann /data/zeng/AODRaw/annotations/train_annotations_downsample_scale3_bbox_min_size32.json --img-dir /data/zeng/AODRaw_downsampled_srgb/AODRaw/images_downsampled_srgb --out /data/zeng/datasets/aodraw'"

# 30 秒后检查（标签文件数应 7000+）
ssh mygpu2 "find /data/zeng/datasets/aodraw -name '*.txt' | wc -l"

# 5.2 启动训练（RTX 4090，batch=16 起步）
ssh mygpu2 "tmux new -s train -d '/data/zeng/miniconda3/envs/rawisp/bin/yolo train detect model=/data/zeng/binocular_isp/data/yolov8n.pt data=/data/zeng/datasets/aodraw/data.yaml epochs=50 imgsz=640 batch=16 device=0 project=/data/zeng/train_results name=aodraw_v1'"

# 5.3 一分钟后验证训练在跑
ssh mygpu2 "ls /data/zeng/train_results/aodraw_v1/ 2>/dev/null; tail -3 /data/zeng/train_results/aodraw_v1/results.csv 2>/dev/null"
```

**报错预案**：`CUDA out of memory` → `ssh mygpu2 "tmux kill-session -t train"` 后把 5.2 命令里 `batch=16` 改 `batch=8` 重跑。
