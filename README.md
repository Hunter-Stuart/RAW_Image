# 下游需求
1. 下游任务是基于双目图像的目标检测，最终输出目标类别、2D/3D位置、距离、尺寸和方向。

2. 输入数据要求
模型侧优先使用经过 ISP 处理的 RGB 图像，建议为：
- RGB888，8 bit/通道；
- sRGB 色彩空间；
- 尽量提供无压缩 PNG，或原始 RGB/YUV，避免高压缩率 JPEG；
- 左右相机分辨率、ISP参数和图像尺寸保持一致。

3. 双目的使用方式
双目左右图像会联合使用，通过左右特征匹配、视差或深度概率估计获取目标深度，然后用于 3D 检测。
因此需要：
- 左右相机严格时间同步；
- 固定且准确的双目标定参数；
- 能够完成去畸变和极线校正；
- 左右图像的曝光、白平衡、Gamma和锐化尽量一致。
4. 重点关注的图像质量指标

- 几何畸变：必须提供准确的左右相机内参、畸变参数、外参、基线长度和投影矩阵。极线校正后，同名点垂直方向误差建议小于 0.5 pixel，最大不超过 1 pixel。
- 时间同步：左右图像时间偏差建议小于 1 ms；动态场景下至少应控制在曝光时间以内。
- 帧率：一般不低于 20 FPS。
- 分辨率：1280×720。
- 延迟：端到端实时应用建议小于 100 ms；图像采集和传输部分越低越好，并需要时间戳可追踪。
- 动态范围：室外、逆光场景建议至少约 70–80 dB；如果存在隧道出入口、强逆光等场景，希望达到 100 dB 左右的 HDR/WDR能力。
- 左右一致性：左右图像亮度、颜色、清晰度和噪声水平应尽量一致，避免两侧独立自动曝光产生明显差异。
- 清晰度：应尽量避免运动模糊、失焦和过度降噪；双目匹配依赖边缘与纹理，过强锐化或降噪都会产生不利影响。
- 曝光：避免大面积过曝和欠曝；动态场景下应优先控制曝光时间，减少运动模糊。
- 图像处理：不建议使用过强的降噪、锐化、局部色调映射和几何裁切。若 ISP 参数会动态变化，需要提供对应元数据。
- 图像完整性：左右相机不能采用不同裁切、缩放或电子防抖，否则必须同步更新相机内参与外参。

5. 希望一并提供的数据
除左右图像外，希望同时提供：
- 左右图像时间戳和帧号；
- 相机内参、畸变参数及左右外参；
- 基线长度和双目校正矩阵；
- 曝光时间、增益、白平衡及 HDR 状态；
- 图像分辨率、帧率和 ISP 配置；

当前优先需要同步、标定准确、ISP一致的双目 sRGB 图像；双目数据会联合用于视差/深度估计和 3D 目标检测。
